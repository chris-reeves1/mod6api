Springboot:

    - controller
        - controls the API entry point.
        - should be simple + thin
        - Listen and recieve requsts decide where to send them.
        
    - DTO
        - data transfer object
        - DTO controls what the client can send
        - DTO controls what the client can see
        - DTO prevents an API exposing state that it shouldnt.
        - DTO extends to db. 

    - validation
        - prevents bad data getting too deep into our app
        - ie: dealt with at api boundary. 

    - Service
        - service is the app logic.
        - example message app:
            - create a message
            - find 
            - delete
        - dont directl call db.

    - repository
        - handles persistance - writes to db.

    - Entity
        - objcts that do into db.
        - MAY HAVE INTERNAL STATE!!! 


status codes:
    - 200 succeded
    - 201 created

    - 400 bad request - invalid input.
    - 404 - no reseource. 

    - 500 - Server error
